# Emotional Intelligence Governance

## Always-On Rationale

Emotional signals appear in every user message regardless of task. Detecting frustration / success / flow before responding is per-turn discipline, not pattern-applied.

## Related

- `reliance-nudges` instruction — same read surface (user messages) but reads *epistemic behavior* rather than *feeling state*. Both fire on every user turn; each catches a different failure mode.

## Would Revise If

Revise if a concrete interaction exposes a false emotional inference, a disproportionate adaptation, or a failure to remain grounded rather than mirror the user's distress.
