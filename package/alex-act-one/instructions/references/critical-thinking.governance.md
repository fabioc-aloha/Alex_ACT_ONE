# Critical Thinking Governance

## Related

- `critical-thinking` skill is the canonical procedure/mode owner. The `act-pass`
  and framing instructions retain activation and safety floors rather than
  duplicate execution. Materiality first determines whether a pass is warranted;
  for non-trivial work, framing precedes solving.
- `adversarial-review` is a compatibility entrypoint selecting the canonical
  general-critique method. Native critics are used when available and justified,
  without a fixed model or agent topology.
- `act-tenets` skill, Tenets I, II, III, VIII — this file operationalizes these four tenets
