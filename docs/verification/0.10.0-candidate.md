## Release Highlights

- Write original fiction and revise specific passages with the standalone
  Creative Writing skill. Preserve protected lines, narrative voice, and
  continuity without adding a runtime dependency.
- Humanizer now flags more short-form patterns, including stacked verdicts,
  vague sourcing, and forced contrasts. Audit-only and Copywriter behavior
  is unchanged; editorial cues are not evidence of authorship.
- Open the bundled Flint Showcase and Interaction Lab offline without a
  checkout or a running MCP server. Both use Flint `1.1.1`; the lab shows
  how highlighting, zooming, and filtering affect linked charts.
- Skip optional dependency setup until a workflow needs it. Setup checks for
  supported fallbacks before proposing an installation and waits for approval.
  The unified installer refreshes only Alex Mall, leaving other catalogs alone.
- Plan can brief explicitly authorized workers and verify their results.
  Linked reports stay in draft when a required file is missing, stale, or
  unverified. Neither change grants permission to publish or send anything.

## Installed Windows Verification

On 2026-11-26, Copilot CLI `1.0.109` reported the enabled Alex Mall package
at `0.10.0`. The installed receipt matched the tagged receipt digest above,
and all 256 listed files passed hash and inventory verification. A no-write
bootstrap preview preserved all 15 instruction files and the current receipt.
This verifies the selected Windows profile's files, not host loading.

- All eight synthetic CLI scenarios completed using the installed package in
  a disposable profile with only skill and reference reads. The responses
  respected the requested boundaries and wrote no workspace files.
- All six npm pins matched; both MCP launchers started. Flint `1.1.1`
  validated a synthetic chart, returned `show`, and served the App UI resource
  over MCP. Both installed demos passed 14 offline Chromium checks each.
- Default dependency verification selected Edge, but Mermaid's browser
  launch failed before SVG-to-PNG verification could run. Both actual renders
  passed in PowerShell 7 and Windows PowerShell 5.1 with the existing Chromium
  passed explicitly using `-BrowserExecutablePath`. Pandoc `3.14` and Pillow
  `13.0.0` passed the dependency checks. Playwright MCP `0.0.84` independently
  required an explicit Chromium executable on this machine: its default
  launch could not find Chrome. With the override, it navigated to a
  synthetic localhost page and returned the expected snapshot.
- Running the tagged integration tests on a temporary copy of the installed
  files against the active runtime yielded 57 of 59 TAP results passing,
  with no skips. One demo-rebuild test failed along with its parent because
  `@napi-rs/canvas` was `1.0.11`, not the build environment's pinned `1.1.0`.
  The real converter and three-backend render checks passed. All four
  installed Rich Email validation tests passed without opening Outlook.

No installs, updates, activation writes, or browser configuration changes
were made. Host restart, native VS Code App UI display and export, Outlook
opening, Scout, the Copilot app, and macOS were not exercised. The release's
manual-install exception does not waive [future release gates](../../RELEASE-CHECKLIST.md).

### Browser Follow-Up

The bare Playwright launch above did not use the installed manifest's Edge
arguments. A separate probe with those exact arguments navigated successfully
to a synthetic localhost page. This does not establish browser tool use inside
the Copilot harness.

The unreleased PowerShell helper now finds cached Playwright Chromium when
the exact browser revision is missing and retains Edge when no cached Chromium
is found. On this Windows setup, the runtime expected revision `1252` and the
browser cache held `1234`. The source helper selected `1234` automatically and
verified real Mermaid SVG and SVG-to-PNG output in PowerShell 7 and 5.1.
Explicit arguments and environment overrides retain priority. The published
payload, profile, and browser configuration were not changed.
