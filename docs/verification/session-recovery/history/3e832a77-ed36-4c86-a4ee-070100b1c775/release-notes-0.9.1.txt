# Alex ACT ONE 0.9.1

This patch fixes the silent document changes found in conversion testing.

## What changed

- HTML conversion preserves uppercase Markdown sources and rejects output/debug
  paths that alias the input, including hard links.
- DOCX conversion gives each output its own extracted-media directory, preserves
  literal code during cleanup, and validates URL-encoded image filenames correctly.
- Converter safety checks reject email-header controls, executable HTML, and
  network/device image paths. Word conversion enforces the PNG raster budget;
  staged document/media publication preserves prior outputs on handled failures.
- The installation helper preserves existing or cross-source packages instead
  of attempting an automatic replacement without rollback.
- Activation fixtures exclude concurrent scratch state and Unix sockets.
  Markdown-link smoke checks cover tracked source documents rather than
  temporary test files.
- Browser acceptance brings resized iframes onscreen, waits for settled geometry,
  retains the one-pixel clipping limit, and validates real keyboard-triggered
  saved downloads.
- Documentation now states the actual Mermaid fallback boundary. Approved project
  guidance, compatibility adapters, workspace settings, and continuity records
  are included.

## Installation and testing

Use the reviewed marketplace route for a fresh installation:

```powershell
copilot plugin marketplace add fabioc-aloha/Alex_Skill_Mall
copilot plugin install alex-act-one@alex-mall
copilot plugin list --json
```

Skip registration if Alex Mall is already registered. Existing Mall users can
refresh that catalog and explicitly update `alex-act-one@alex-mall`. If switching
from a direct repository candidate, close hosts and explicitly resolve the old
installation first; do not keep duplicate delivery sources.

Verify the loaded version/root, restart the host, then preview `bootstrap-core`
and approve its exact target/actions before activation. Plugin installation does
not itself replace previously activated instructions. Runtime pins are unchanged;
this patch requires no runtime upgrade.

## Evidence limits

This is scoped verification for further testing, not certification of every
skill or host. Scout and the Copilot app were not freshly tested. Native-host
download completion, screen-reader speech, every chart's keyboard/contrast
behavior, macOS, a dedicated vulnerability audit, paid Replicate requests,
Outlook sending, and recoverable runtime upgrades are not established.
