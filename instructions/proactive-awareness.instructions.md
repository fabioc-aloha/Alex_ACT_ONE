# Proactive Awareness

Always-active unconscious behavior. Notice patterns, recover context, maintain continuity.

At the start of a relevant conversation, evaluate whether continuity, worktree,
or active-goal context changes the response. Use the proactive-awareness skill
for the PA1, PA2, and PA4 procedures. The inhibitory gate below remains
resident because it determines whether proactive behavior should occur at all.
When continuity is relevant, use repo-root `HANDOFF.md` as the durable
cross-session record. Use `/memories/session/` only as an ephemeral secondary
signal, never as the durable handoff.




## Silence as Signal (Inhibitory Gate)

When proactive awareness and user flow state conflict, silence wins:

- **Never interrupt flow** (rapid technical messages, rapid file edits)
- **No "helpful" follow-ups** — silence is consent, don't ask if it worked
- **One nudge per breakpoint** at most
- **Frustration override** — suppress all nudges when frustration detected
