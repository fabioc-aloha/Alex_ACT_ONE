# Scoped completion and debt handling

Repair stale references and debt caused by or tightly coupled to the approved task. Preserve unrelated work. If a necessary repair is risky, requires architectural redesign, or exceeds authority, name the precise blocker and ask for the user decision. Use the existing task record rather than a new ledger. Do not defer silently or report completion while an enumerated requirement is blocked. Do not interpret discovery as permission for unrelated cleanup.
